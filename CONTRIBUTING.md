# Contributing

Issues and pull requests are welcome for the Lite feature set: BYOK basic reverse analysis, local palettes, display-only translation, localization, accessibility and local history.

Please do not submit:

- API keys, personal images, provider responses or browsing data;
- copied proprietary prompts or reverse-engineered private workflows;
- EYROVE Pro source, generation, billing or provider-fallback code;
- remote scripts, telemetry or undeclared network destinations.

Run `npm test` before opening a pull request. Changes to permissions, storage or network behavior must update `PRIVACY.md`, `SECURITY.md` and the README.
